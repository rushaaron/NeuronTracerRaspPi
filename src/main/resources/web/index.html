Neuron Tracer

A head start on hand tracing, for the NeuronJ plugin for Fiji.

Upload an image of a sensory neuron and this will attempt to trace it and gather statistics on the result. You get back an NDF file you can open in NeuronJ to continue where the tracer left off, plus JPEGs that show what it found.

Images are traced in memory and thrown away as soon as the result is sent back. Nothing is stored on the server.

How to use it

  1. For best results, fill in the cell body with a pink color. Otherwise the tracer will try to detect it automatically, but if it is not dark enough the results may vary.
  2. Choose a sensory neuron image. See the examples further down the page.
  3. Adjust the tuning values if you need to, then press Trace image.
  4. Check the preview to see how the trace turned out.
  5. Download the archive to get the traced images and the NDF file.
